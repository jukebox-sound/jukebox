=head1 NAME

jukebox - music player and library browser for large audio collections

=head1 SYNOPSIS

B<jukebox> [I<OPTIONS>] [I<FILE> | I<DIRECTORY> ...]

B<jukebox> B<-cmd> I<COMMAND> [B<-cmd> I<COMMAND> ...]

B<jukebox> B<-tagedit> I<FILE> | I<DIRECTORY> ...

B<jukebox> B<-listcmd> | B<-listlayout> | B<-listplugin>

=head1 DESCRIPTION

B<jukebox> is a GTK2/Perl music player derived from gmusicbrowser.  It
is designed around a local music library, configurable layouts,
filters, queues, playlists, and optional plugins.

Files and directories given on the command line are normally opened as
the playlist.  The B<-add>, B<-enqueue>, B<-addplaylist>, and
B<-insertplaylist> options change how those arguments are handled.
When another jukebox instance is already running, commands and file
operations are forwarded through DBus or the command FIFO when
possible.

=head1 OPTIONS

=head2 Startup and library handling

=over

=item B<-c>, B<-nocheck>

Do not check the library for changed or deleted files at startup.

=item B<-s>, B<-noscan>

Do not scan configured library folders for new songs at startup.

=item B<-demo>

Do not save settings or tags when the process exits.

=item B<-ro>

Prevent modifying, renaming, or deleting song files.  This also enables
tag read-only mode.

=item B<-rotags>

Prevent modification of tags in audio files.

=item B<-play>

Start playback after startup.

=item B<-hide>

Start with the main window hidden.

=item B<-geometry> I<GEOMETRY>

Set the initial window geometry.

=back

=head2 Playback and services

=over

=item B<-nogst>

Do not load a GStreamer backend.

=item B<-gst0>

Prefer the GStreamer 0.10 backend over GStreamer 1.x when both are
available.

=item B<-server>

Use server playback mode and send the playing stream to connected
clients.

=item B<-port> I<N>

Listen on port I<N> in server mode.

=item B<-nodbus>

Do not provide jukebox DBus services.

=item B<-dbus-id> I<KEY>

Append C<.KEY> to the default C<org.jukebox> DBus service id.  The key
may contain letters, numbers, and underscores.

=back

=head2 Configuration and interface

=over

=item B<-C> I<FILE>, B<-cfg> I<FILE>

Use I<FILE> instead of the default C<jukeboxrc>.  If the argument is an
existing directory, or ends in C</>, use it as the jukebox configuration
directory instead.

=item B<-F> I<FIFO>, B<-fifo> I<FIFO>

Use I<FIFO> as the command FIFO instead of C<jukebox.fifo> in the
configuration directory.

=item B<-nofifo>

Do not create or use a command FIFO.

=item B<-l> I<NAME>, B<-layout> I<NAME>

Use layout I<NAME> for the player window.

=item B<+plugin> I<ID>

Enable plugin I<ID> for this startup.

=item B<-plugin> I<ID>

Disable plugin I<ID> for this startup.

=item B<-noplugins>

Disable all plugins for this startup.

=item B<-searchpath> I<DIRECTORY>

Add I<DIRECTORY> to the search path for plugins and layouts.  This
option may be used more than once.

=item B<-workspace> I<N>

Move the initial window to workspace I<N>.  This requires the
C<Gnome2::Wnck> Perl module.

=item B<-use-gnome-session>

Use the GNOME session interface when available so settings and tags can
be saved during session logout.

=item B<-import> I<FILE>

Import state from I<FILE> instead of loading the normal saved state.

=item B<+gzip>

Save C<jukeboxrc> compressed with gzip.

=item B<-gzip>

Save C<jukeboxrc> without gzip compression.

=item B<+xz>

Save C<jukeboxrc> compressed with xz.

=back

=head2 Commands and existing instances

=over

=item B<-cmd> I<COMMAND>

Execute a jukebox command.  The option may be repeated.  If a running
instance is found, the commands are forwarded to it.  Use B<-listcmd>
to obtain the commands supported by the current build.

=item B<-ifnotrunning> I<MODE>

Select what happens when B<-cmd> or a file operation cannot find a
running instance.  I<MODE> is one of:

=over

=item C<normal>

Start a new instance and execute the requested commands.  This is the
default.

=item C<nocmd>

Start a new instance but discard the requested commands.

=item C<abort>

Do not start a new instance.

=back

=item B<-nolaunch>

Equivalent to C<-ifnotrunning abort>.

=back

=head2 File argument actions

=over

=item B<-playlist>

Use file and directory arguments as the playlist.  This is the default.

=item B<-enqueue>

Enqueue file and directory arguments.

=item B<-addplaylist>

Append file and directory arguments to the playlist.

=item B<-insertplaylist>

Insert file and directory arguments in the playlist after the current
song.

=item B<-add>

Add file and directory arguments to the music library.

=item B<-tagedit> I<FILE_OR_DIRECTORY> ...

Open the tag editor for the supplied files or directories.

=back

=head2 Diagnostics and discovery

=over

=item B<-verbose>

Print operational information, including the file being played.

=item B<-debug>

Enable verbose debugging output.  This implies B<-verbose>.

=item B<-backtrace>

Print a Perl backtrace for warnings and fatal errors.

=item B<-listcmd>

List available jukebox commands and exit.

=item B<-listlayout>

List available layouts and exit.

=item B<-listplugin>

List available plugins and exit.

=item B<-h>, B<--help>

Print the command-line help and exit.

=back

=head1 CONFIGURATION

The default configuration directory is
F<$XDG_CONFIG_HOME/jukebox/>.  When C<XDG_CONFIG_HOME> is unset, Glib's
user configuration directory is used, normally F<~/.config>, making the
usual path F<~/.config/jukebox/>.

For compatibility, if the XDG directory does not yet exist and
F<~/.jukebox/> does exist, jukebox uses F<~/.jukebox/> and prints a
migration warning.

The primary state file is C<jukeboxrc>.  It contains application
options and library metadata and is written by jukebox.  See
L<jukeboxrc(5)> for its role and safe handling.

=head1 FILES

=over

=item F<$XDG_CONFIG_HOME/jukebox/jukeboxrc>

Saved application options, library metadata, playlists, and other
persistent state.  The file may instead have a C<.gz> or C<.xz>
suffix when compression is enabled.

=item F<$XDG_CONFIG_HOME/jukebox/jukebox.fifo>

Command FIFO used for inter-process control unless B<-nofifo> is used.
For example:

  printf '%s\n' 'PlayPause' > ~/.config/jukebox/jukebox.fifo

Use C<jukebox -listcmd> for the authoritative command list.

=item F<$XDG_CONFIG_HOME/jukebox/plugins/>

User plugins.

=item F<$XDG_CONFIG_HOME/jukebox/layouts/>

User layouts.

=item F<$XDG_CONFIG_HOME/jukebox/icons/>

User-provided icons referenced by layouts and interface elements.

=item F</usr/share/jukebox/>

System data directory in the default installation.  It contains the
Perl modules, default configuration, layouts, plugins, and bundled
artwork.  The path follows the installation prefix and may differ on a
packaged system.

=back
